## Overview

**SvaraAI** merupakan asisten digital cerdas yang dikembangkan untuk memfasilitasi pengolahan dokumen secara cepat dan otomatis. Mengintegrasikan beberapa kapabilitas pemrosesan bahasa alami (NLP) seperti ekstraksi teks (OCR), summarization, translation, hingga sintesis ucapan (Text-to-Speech).

Aplikasi dirancang dengan arsitektur backend asynchronous yang kuat, memungkinkan pemrosesan dokumen besar secara non-blocking dengan responsivitas tinggi.

## Key Features

- **Optical Character Recognition (OCR)**: Ekstraksi teks dari gambar dokumen, scan artikel, maupun catatan menggunakan model vision mutakhir.
- **Peringkasan Dokumen Cerdas**: Menghasilkan ringkasan dokumen otomatis dengan mempertahankan poin-poin esensial.
- **Penerjemahan Kontekstual**: Menerjemahkan kalimat lintas bahasa dengan memahami nuansa bahasa dan konteks industri.
- **Neural Text-to-Speech (TTS)**: Mengonversi teks hasil analisis menjadi suara alami dengan berbagai pilihan intonasi dan kecepatan.
- **Smart File Handling**: Ekspor hasil ringkasan ke berbagai format dokumen siap unduh (.txt, .pdf).

## Technologies Used

- **FastAPI & Python**: Arsitektur mikroservis backend asynchronous berlatensi rendah.
- **LLM APIs**: Integrasi model bahasa skala besar untuk reasoning dan ekstraksi data kontekstual.
- **Next.js & TypeScript**: Dashboard web modern untuk monitoring antrian dokumen dan visualisasi hasil.
- **Docker & Cloud Run**: Deployment terisolasi berbasis kontainer untuk skalabilitas elastis.

## Challenges and Learnings

Tantangan utama adalah menjaga keakuratan OCR pada dokumen pindaian beresolusi rendah atau dengan orientasi miring. Pendekatan preprocessing citra (deskewing, binarization, dan contrast enhancement) diimplementasikan sebelum gambar diproses oleh OCR engine, meningkatkan akurasi pembacaan teks hingga 28%.

## Outcome

SvaraAI berhasil mengotomatisasi alur kerja pengolahan dokumen, memangkas waktu review berkas dari rata-rata 15 menit menjadi kurang dari 45 detik. Platform ini kini digunakan untuk memproses ratusan dokumen per minggu dengan tingkat keandalan tinggi.
