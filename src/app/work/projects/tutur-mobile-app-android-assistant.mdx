## Overview

**TUTUR** adalah aplikasi yang dirancang untuk membantu anak-anak dengan gangguan bicara dan bahasa. Aplikasi ini mengadopsi metode **Picture Exchange Communication System (PECS)** agar anak dapat meningkatkan pemahaman kata dan kalimat dalam berkomunikasi sehari-hari.

Proyek ini tidak hanya berfokus pada pengembangan perangkat lunak, tetapi juga pada penciptaan dampak sosial nyata. Melalui ajang **Innovillage 2024**, pengembangan TUTUR berkolaborasi langsung dengan terapis wicara, guru pendidikan luar biasa (PLB), dan komunitas lokal untuk memastikan bahwa aplikasi ini benar-benar menjawab kebutuhan riil pengguna di lapangan.

## Key Features

- **Sistem Komunikasi PECS**: Memungkinkan pengguna menyusun dan menyampaikan pesan dengan mudah menggunakan kartu bergambar yang merepresentasikan kata atau tindakan.
- **Kategori yang Dapat Dikustomisasi**: Konten, kosakata, dan gambar dapat disesuaikan dengan kebutuhan serta tingkat pemahaman individu anak untuk memastikan efektivitas komunikasi.
- **Pembelajaran Interaktif (Visual & Audio)**: Menggabungkan pengenalan kata melalui gambar dan suara secara bersamaan untuk mempercepat proses penyerapan informasi.
- **Sistem Reward (Penghargaan)**: Fitur gamifikasi sederhana untuk memotivasi dan mendorong anak agar terus menggunakan aplikasi secara aktif dan menyenangkan.

## Technologies Used

- **Flutter**: Digunakan sebagai framework utama untuk membangun antarmuka aplikasi mobile yang interaktif, responsif, dan dapat berjalan secara lintas platform.
- **Firebase Authentication**: Diimplementasikan untuk mengelola sistem keamanan login dan pendaftaran akun pengguna secara aman.
- **Laravel (RESTful API)**: Digunakan sebagai fondasi backend server untuk mengelola sinkronisasi data pengguna, penyimpanan aset gambar/suara, dan kelancaran fitur aplikasi secara real-time.
- **Google Cloud Platform (GCP)**: Digunakan sebagai infrastruktur cloud terintegrasi untuk men-deploy dan meng-hosting server backend Laravel, sekaligus memanfaatkan layanan Cloud Bucket Storage untuk mengelola dan menyimpan aset media pengguna.

## Challenges and Learnings

Membangun aplikasi untuk audiens dengan kebutuhan khusus memberikan tantangan tersendiri, terutama dalam merancang *User Interface* (UI) dan *User Experience* (UX) yang tidak membebani aspek kognitif anak. Mengintegrasikan logika penyusunan kalimat dari gambar (PECS) dan memastikannya berjalan dengan lancar tanpa *latency* membutuhkan optimasi *state management* yang baik di dalam Flutter.

Selain itu, berkolaborasi dengan ahli non-teknis seperti terapis wicara dan pendidik mengajarkan cara menerjemahkan kebutuhan ke dalam *software development lifecycle* yang sistematis dan terstruktur.

## Outcome & Achievements

TUTUR telah berhasil diimplementasikan sebagai media pembelajaran dan alat komunikasi alternatif yang efektif. Aplikasi ini memberikan pengalaman yang baru bagi anak-anak sekaligus memudahkan orang tua dan pendidik dalam memantau perkembangan mereka.

Sebagai bentuk pengakuan atas dampak sosial dan ekonominya, proyek TUTUR berhasil meraih **Juara 1 pada Tema Disabilitas, Kategori Inovasi Creating Shared Value (CSV) di ajang Innovillage 2024**. Penghargaan ini membuktikan bahwa solusi teknologi yang dibangun dengan empati mampu membawa dampak positif bagi pengguna.
